# Character icons

The files in this folder are the `Agent <Name> Circle Icon.png` portraits from
the [Zenless Zone Zero Wiki](https://zenless-zone-zero.fandom.com/wiki/Zenless_Zone_Zero_Wiki)
(Fandom), downloaded and converted to WebP for offline use in the sidebar.

They are used only to identify a character. Zenless Zone Zero and its character
artwork are © HoYoverse; the wiki's text and images are available under
CC BY-SA 3.0 unless stated otherwise on the source file page.
